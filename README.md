## Repository Structure

Beyond the documentation, this repository includes configurations and scripts to automate daily tasks:

*   **`alacritty/`**: Custom configuration (`alacritty.toml`) and required fonts for the Alacritty terminal emulator.
*   **`github_automation/`**: Shell scripts designed for bulk cloning and managing GitHub repositories.
*   **`music_download_ytdlp/` & `video_download_script/`**: Custom bash scripts leveraging `yt-dlp` to parse text files and batch-download media.
*   **`wallpapers/`**: A curated collection of high-resolution desktop backgrounds.
